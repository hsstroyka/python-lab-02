# Лабораторная работа №2 - потоковый анализатор файлов на Python

## Описание проекта

Проект представляет собой консольный пакет `streamstats`, предназначенный для построчного чтения файлов CSV и JSONL, проверки данных и получения статистики по событиям.

Каждое событие содержит четыре обязательных поля:

- `timestamp` — дата и время события;
- `level` — уровень события;
- `source` — источник события;
- `message` — текст сообщения.

Поддерживаемые уровни событий: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`.

Программа выполняет следующие действия:

**1. Чтение файлов (`parsers`)**: читает файлы CSV и JSONL построчно без загрузки всего файла в оперативную память.

**2. Проверка событий (`models`)**: проверяет наличие обязательных полей, правильность даты и уровня события.

**3. Анализ данных (`analysis`)**: подсчитывает общее количество событий, количество событий каждого уровня и источника, находит топ-5 источников ошибок ERROR и CRITICAL, определяет первую и последнюю временную метку.

**4. Создание отчёта (`report`)**: сохраняет полученную статистику в JSON-файл.

Программа также позволяет объединять статистику нескольких файлов и обрабатывать неправильные строки.

## Настройка и запуск

**Сначала необходимо установить пакет, введя в терминале команду:**

```
python -m pip install -e .
```

**После установки можно запускать программу через командную строку.**

## Примеры использования:

**Запуск анализа CSV-файла:**

Например, чтобы проанализировать файл `events.csv` и сохранить результат в `report.json`, нужно написать:

```
python -m streamstats analyze examples/events.csv --format csv --output report.json
```

**Запуск анализа JSONL-файла:**

```
python -m streamstats analyze examples/events.jsonl --format jsonl --output report.json
```

**Анализ нескольких файлов:**

```
python -m streamstats analyze file1.csv file2.csv --format csv --output report.json
```

**Пропуск неправильных строк:**

Если в файле есть ошибочные строки, можно использовать `--skip-invalid`. Тогда программа пропустит их и продолжит обработку.

```
python -m streamstats analyze examples/events.csv --format csv --skip-invalid
```

**Показать справку по использованию:**

```
python -m streamstats --help
```

или

```
python -m streamstats -h
```

## Обработка ошибок

Программа проверяет наличие всех обязательных полей, правильность даты и уровня события.

Если обнаружена неправильная строка, обработка прекращается и выводится сообщение с номером файла и строки. Программа завершается с кодом 2.

При использовании `--skip-invalid` неправильные строки пропускаются, выводится предупреждение WARNING, а количество пропущенных строк добавляется в отчёт.

## Потоковая обработка

Файлы читаются построчно с помощью циклов и `yield`.

Программа не загружает весь файл в память, а обрабатывает события по одному. Это позволяет работать с большими файлами без хранения всех событий в списке.
